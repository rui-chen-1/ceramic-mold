Style guide

Every element an essay can use, for checking the theme. Not listed anywhere; open it at /essays/style-guide/.

Body text is set at 18 pixels on every screen. Italic is for emphasis, book titles such as Camera Lucida, and foreign terms, never for titles or headings. A link looks like this; it turns oxide red on hover.

A section heading

A paragraph after a heading. A sidenote sits in the margin on wide screens.1This is a sidenote, written with the sidenote shortcode. Markdown works inside it. On a phone it folds into the text and its number toggles it.

A sub-heading with emphasis

Emphasis inside a heading turns into weight, not italic.

A block quote is muted and set off by one hairline, with no quotation-mark ornament.
